# 🔗 Singly Linked List in C++

## 📖 Overview

This project demonstrates the implementation of a **Singly Linked List** in C++ using object-oriented programming.

It covers the core operations needed to manage a dynamic list of elements efficiently.

---

## ⚙️ Features

✔ Insert elements at the end
✔ Delete a node by value
✔ Display the list
✔ Automatic memory cleanup (Destructor)

---

## 🧠 How It Works

The program is built using two main classes:

### 🔹 Node

Represents each element in the list:

* `data`: stores the value
* `next`: pointer to the next node

### 🔹 LinkedList

Manages the entire list:

* Keeps track of the head node
* Handles all operations

---

## 🔧 Functions Breakdown

### ➤ insertAtEnd(int value)

Adds a new node at the end of the list.

### ➤ deleteByValue(int value)

Removes the first node that contains the given value.

### ➤ display()

Prints the list in a readable format:
10 -> 20 -> 30 -> NULL

---

## ▶️ Example Run

Linked List: 10 -> 20 -> 30 -> NULL
After Deleting 20: 10 -> 30 -> NULL
